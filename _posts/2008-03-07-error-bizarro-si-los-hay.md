Si alguna vez estan trabajando con MySQL y se encuentran con el siguiente error

The code throws a SQLException with the stack trace java.sql.SQLException: Unable to connect to any hosts due to exception: java.lang.ArrayIndexOutOfBoundsException: 44

Antes de cortarse las venas, traten de cambiar el nombre de la base de datos con la que se estan conectando a cualquier nombre que no posea la satanica suma de 9 caracteres...
