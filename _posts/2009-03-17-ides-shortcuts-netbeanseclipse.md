Aca van algunos de los shortcuts que mas uso.. mas que nada para que no se me olviden.

### **Netbeans:**

**Search a Class By Name:** CTRL+O

**Search a File/Resource By Name:** ALT+SHIFT+O

**Inspect Class Methods and Properties:** CTRL+F12

**Inspect Class Hierarchy:** ALT+SHIFT+F12

**Contextual Refactoring:** ALT+INSERT

**Find Usages:** ALT+F7

**Select In:** CTRL+SHIFT+1 , 2 (Projects, Files)

**Switch Source File**:  CTRL+TAB

### **Eclipse:**

**Search a Class By Name:** CTRL+SHIFT+T

**Search a File/Resource By Name:** CTRL+SHIFT+R

**Inspect Class Methods:** CTRL+O

**Inspect Class Hierarchy:** CTRL+T

**Contextual Refactoring:** CTRL+3

**Find Usages (References):** CTRL+SHIFT+G (en el workspace)

**Select In:** ALT+SHIFT+W

**Switch Source File**:  CTRL+PGUP / CTRL+PGDOWN
