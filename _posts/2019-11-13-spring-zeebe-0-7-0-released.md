I am happy to announce that [Spring Zeebe 0.7.0](https://search.maven.org/artifact/io.zeebe.spring/spring-zeebe-starter/0.7.0/jar) has been released using Zeebe Core 0.21.1 and Spring Boot 2.2.0.RELEASE.

If you find any issues with these projects [please report them here](https://github.com/zeebe-io/spring-zeebe/issues).

Moving forward we want to quickly align Spring Zeebe projects with Zeebe releases in a more coordinated way and we want to refine these projects dependencies to make sure that they are aligned with the Spring Boot release train. I will be leading this process with the original author of these modules ***Jan Galinski*** from ***[Holisticon](https://holisticon.de)*** to make sure that we keep these projects community driven with a transparent governance.

If you have questions, proposals or extensions related to Spring Zeebe please get in touch. I will be more than happy to organize the contribution process and mentor you with your first Pull Request.
