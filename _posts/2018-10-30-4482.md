Last week we worked hard on [Beta2 release](/2018/10/30/activiti-core-activiti-cloud-beta2-released/). We manage to upgrade our [HELM charts](http://github.com/activiti/activiti-cloud-charts) and test the modeling services to make sure that the basic features included in Beta2 were covered. We are also increasing our Test Coverage for distributed architectures and we will include into our release process the [Acceptance Tests](https://github.com/Activiti/activiti-cloud-acceptance-tests) modules once we refactor them to a releasable shape.

[@lucianoprea](https://github.com/https://github.com/lucianoprea)  worked on improving the consistency of update operations across core services updating the task admin in runtime-bundle.

[@daisuke-yoshimoto](https://github.com/daisuke-yoshimoto) worked on adding Transaction SubProcess Symbol to ProcessDiagramGenerator. Please review pr. <https://github.com/Activiti/Activiti/pull/2088>

[@almerico](https://github.com/almerico) Working on Alfresco DBP installation on GCP

[@mteodori](https://github.com/mteodori) created issue [#2076](https://github.com/Activiti/Activiti/issues/2076) and PR [#2077](https://github.com/Activiti/Activiti/pull/2077) to test engine with OpenJDK 11 on Travis

[@constantin-ciobotaru](https://github.com/constantin-ciobotaru) added more fixes in modeling and testing for the Beta2

[@miguelruizdev](https://github.com/miguelruizdev) worked on the admin scenarios in the acceptance test as well as testing the new modeler call activities.

[@ryandawsonuk](https://github.com/ryandawsonuk) Tested what we could produce with the current version of the new modeler and checked that we could create runtime bundles from the zipped application output. Updated the release scripts and built test images of the examples. Validated the test images before initiating the Beta2 release and checking the release artifacts.

[@erdemedeiros](https://github.com/erdemedeiros) finished import of application zip and updated processes discovery mechanism to allow the discovery of processes at different level (i.e. /processes and /some/path/processes). Tested latest changes for Beta2.

[@salaboy](http://twitter.com/salaboy) worked on [Beta2 preparation](/2018/10/30/activiti-core-activiti-cloud-beta2-released/) and testing, release notes and video.

Get in touch if you want to contribute: <https://gitter.im/Activiti/Activiti7>

We are looking forward to mentor people on the technologies that we are using to submit their first Pull Request ;)
