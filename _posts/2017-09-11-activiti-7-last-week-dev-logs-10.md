Last week (**4/9/17 - 10/9/17**) we spend a lot of time refining our deployments mechanism to fit both Docker Compose and Kubernetes (and Minikube). We worked with [@ryandawsonuk](https://github.com/ryandawsonuk) to polish our examples and make sure that you can bootstrap the infrastructure following a finite number of steps :) A blog post about this is coming today.

[@daisuke-yoshimoto](https://github.com/daisuke-yoshimoto) provided a [PR for Mongo DB](https://github.com/Activiti/Activiti/pull/1458) integration for the audit service and

[@gmalanga](https://github.com/gmalanga) provided a [PR for ElasticSearch](https://github.com/Activiti/Activiti/pull/1454) integration for the query module. Help us to review these PRs!

We got an update form [@igdianov](https://github.com/igdianov) which is working our new GraphQL endpoints so we are looking forward to review all these contributions.

Besides that we started adding content in our GitBook: <https://activiti.gitbooks.io/activiti-7-developers-guide/content/chapter1.html>, feel free to send comments/issues and PR for that repository as well. This GitBook will have a section for each of our components and links to related resources.

This week we ([@ryandawsonuk](https://github.com/ryandawsonuk)  and myself) are going to be a little bit off (UK working hours) the Gitter Channel, because we are in Seattle WA USA. If you are around and want to code/hangout drop us a message.
